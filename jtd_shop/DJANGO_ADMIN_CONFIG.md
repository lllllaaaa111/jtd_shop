# Django管理页面配置说明

## 概述
Django管理页面已精简配置，只显示核心业务表，提供清晰简洁的管理界面。

## 显示的核心表

### 1. 用户管理
- **用户 (User)**: 用户基本信息管理
- **组 (Group)**: 用户权限组管理

### 2. 商品管理
- **商品分类 (Category)**: 商品分类管理
- **商品 (Product)**: 商品信息管理（包含图片和描述内联编辑）

### 3. 订单管理
- **订单 (Order)**: 订单信息管理（包含订单商品和物流信息内联编辑）
- **购物车 (Cart)**: 购物车商品管理

### 4. 内容管理
- **欢迎页面 (Welcome)**: 首页欢迎内容管理

### 5. 系统管理
- **微信支付配置 (SystemConfig)**: 微信支付相关配置

## 隐藏的管理表

以下表不在主管理页面显示，通过相关表的内联编辑进行管理：

### 用户相关
- 用户地址 (Address)
- 用户头像 (Mine)

### 商品相关
- 商品图片 (ProductImage)
- 商品描述 (ProductDescription)

### 订单相关
- 物流信息 (LogisticsInfo)
- 物流状态日志 (LogisticsStatusLog)
- 订单状态日志 (OrderStatusLog)

### 内容相关
- 横幅 (Banner)
- 文章 (Article)
- 公告 (Notice)

### 系统相关
- 操作日志 (OperationLog)
- 文件上传 (FileUpload)
- 数据备份 (DataBackup)

## 配置说明

### 自定义CSS
位置：`jtd_shop/static/admin/css/admin_custom.css`
- 改善表格字段对齐
- 优化内联表格显示
- 统一按钮和状态样式

### Admin配置
位置：`jtd_shop/admin_config.py`
- 控制显示的核心表
- 设置站点标题和样式

### 模板配置
位置：`jtd_shop/templates/admin/base_site.html`
- 加载自定义CSS
- 设置站点标题

## 使用方法

1. 访问 `/admin/` 进入管理页面
2. 使用核心表进行业务管理
3. 通过内联编辑管理相关子表
4. 利用搜索和过滤功能快速定位数据

## 注意事项

- 物流信息通过订单页面的内联编辑进行管理
- 商品图片和描述通过商品页面的内联编辑进行管理
- 用户地址和头像通过用户页面的内联编辑进行管理
- 所有操作都有相应的日志记录（通过API接口查看）
